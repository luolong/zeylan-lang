= How to Mock Databases in Unit Tests
:navtitle: Mock Databases

This guide shows how to inject in-memory test doubles for database effects without Dependency Injection frameworks.

[source,zeylan]
----
shared void testGetProfile() {
    val mockDb = InMemoryDatabase();
    val silentLogger = NoOpLogger();

    val profile = handle {
        getProfile("usr_123");
    } with {
        Database => mockDb;
        Logger => silentLogger;
    };

    assert(profile.name == "Test User");
}
----
