= Compiler Developer Setup
:navtitle: Dev Environment

How to set up Java 25, GraalVM, and Bazel for contributing to the Bourbon compiler.

== Requirements

* Java 25 / GraalVM JDK 25+
* Bazel build tool

== Building and Running the Compiler

We use `mise` to manage development tools and versions (like Bazel and Java). To build and run the compiler, use the following commands:

=== Build the Native Compiler

To build the standalone native compiler binary `bourbon`:

[source,shell]
----
mise exec -- bazel build //compiler:bourbon
----

=== Run the Compiler (Native)

To run the native compiler and see its CLI options:

[source,shell]
----
mise run bourbon --help
----

To run the native compiler REPL session:

[source,shell]
----
mise run bourbon
----

=== Run the Compiler (JVM-based)

To avoid GraalVM compilation time (20s+) during development, you can run the JVM-based compiler, which starts up instantly:

To see CLI options:

[source,shell]
----
mise run bourbon-jvm --help
----

To launch the JVM REPL session:

[source,shell]
----
mise run bourbon-jvm
----

NOTE: Direct `bazel run` executions of interactive CLI commands (like the REPL) can fail or lose TTY support due to Bazel's run sandbox environment. Always use `mise run` commands to compile with Bazel and run directly on the host.

=== Custom Bazel Targets

All general Bazel commands should be prefixed with `mise exec --` (or `mise x --`) to ensure the correct versions of Bazel and Java are loaded:

[source,shell]
----
mise exec -- bazel <command> <targets>
----

== Building Documentation

We use link:https://mise.jdx.dev/[mise] to manage tool dependencies (Java, Node.js, Bazel, etc.) and run tasks.

To generate the documentation site:

[source,shell]
----
mise run docs:build
----

The output will be built in the `./build/site` directory.

NOTE: Antora requires the local project directory to be a Git repository.
Since this project is set up with Jujutsu using a colocated Git backend, the Git repository requirement is satisfied automatically.
