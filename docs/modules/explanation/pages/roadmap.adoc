= Layered Roadmap
:navtitle: Roadmap

Rather than an "all-or-nothing" monolithic language release, Bourbon is engineered in four usable, incremental language dialects, backed by a full standard library and tooling suite.

== Layer 1: Core Pure Dialect (The Mathematical Foundation)

* *Scope*: Primitive types, immutability, pure function verification, set-theoretic types (`A | B`, `A & B`), structural subtyping, and flow-sensitive type narrowing (`is`, `exists`).
* *Deliverable*: A fully functional, standalone pure language that compiles to native code, WebAssembly, or C for mathematical calculations, business rules, and algorithmic processing with zero runtime overhead.

== Layer 2: Local Algebraic Effects & Handlers

* *Scope*: `performs` annotations, `guard handle` expressions, first-class handler values, and local effect subtraction (`E \ H`).
* *Standard Library Additions (`std.core`)*:
  * `Error` & `Option` effects (type-safe early returns without exceptions).
  * `State<T>` & `Reader<R>` effects (explicit mutable state boundaries).
  * `Logger` capability interface.

== Layer 3: Concurrency, Async & System I/O

* *Scope*: Delimited continuations, stack-switching runtime, and non-blocking execution primitives.
* *Standard Library Additions (`std.io` / `std.async`)*:
  * Core I/O drivers (File, Socket, HTTP, Process).
  * Structured Concurrency primitives (Fibers, Channels, Task cancellation).
  * Streaming data processing abstractions.

== Layer 4: Capability Boundaries & Ecosystem Security

* *Scope*: Module-level capability bounds (`module.bourbon`), compile-time taint tracking (`Tainted<T>` vs `Sanitized<T>`), and domain-specific string interpolators (`sql"..."`).
* *Ecosystem & Tooling (Batteries Included)*:
  * `bourbon` CLI & Build System: Fast compilation, test runner, dependency resolution.
  * Package Registry (`bourbon.dev`): Zero-trust package registry enforcing module capability grants.
  * IDE & Tooling: Language Server Protocol (LSP) implementation, tree-sitter grammar, auto-formatter (`bourbon fmt`), and static analysis tools.
