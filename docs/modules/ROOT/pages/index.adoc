= Bourbon Programming Language
:navtitle: Overview

Welcome to the documentation for **Bourbon**—a modern programming language built on set-theoretic types (`A | B`, `A & B`, `E \ H`), algebraic effect inference, explicit purity, first-class handlers, and zero-trust capability security.
