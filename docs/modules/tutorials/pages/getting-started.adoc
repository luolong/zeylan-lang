= Getting Started with Bourbon
:navtitle: Getting Started

This tutorial guides you step-by-step through installing Bourbon, writing your first `pure` functions, and compiling a program.

== Prerequisites

* JDK 26 or GraalVM 26+ installed.

== Writing Hello World

[source,bourbon]
----
shared void main() {
    print("Hello, Bourbon!");
}
----

== Pure Calculations

Functions in Bourbon are pure calculations unless marked with capabilities:

[source,bourbon]
----
shared pure Float calculateTax(Float amount, Float rate) => amount * rate;
----
